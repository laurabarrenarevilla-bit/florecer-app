# Prototipo visual

`claude-design-v2.dc.html` procede de la segunda iteración de Claude Design. Es material de referencia para maquetación, textos y estructura de pantallas. NO se puede usar como aplicación funcional: depende del runtime `support.js`, contiene `x-dc`/`DCLogic`, fechas ancladas a 2026-11-08, fixtures, login falso, guardado en memoria, palabras y análisis IA falsos. También contiene mensajes de privacidad que deben corregirse para nube. No copiar los datos demo a la producción.

**Guía de diseño**: móvil primero, crema/salvia, DM Sans/Fraunces, 4 tabs, selector de 3 moods, celdas calendario coloreadas, evolución con timeline y privacidad visible. `06-DESIGN-AND-SASS.md` tiene prioridad sobre implementaciones técnicas del prototipo.
